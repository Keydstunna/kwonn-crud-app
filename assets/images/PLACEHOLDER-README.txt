Ilagay dito ang mga background image mo (ikaw na bahala mag-source, K):

  login-bg.jpg           -> background ng index.php (login page)
  cleanup-bg.jpg         -> background ng events/cleanup/ (Clean-Up Drive)
  treeplanting-bg.jpg    -> background ng events/treeplanting/ (Tree Planting)
  choose-event-bg.jpg    -> optional, background ng choose-event.php

Kahit wala pang laman itong folder, gagana pa rin lahat ng pages —
gradient lang muna ang lalabas na background hangga't wala ka pang
nailalagay na image dito (may CSS fallback na naka-set up na).

Recommended size: 1920x1080 o mas malaki, landscape na larawan ng
ilog/baybayin (cleanup) o gubat/puno (tree planting).
